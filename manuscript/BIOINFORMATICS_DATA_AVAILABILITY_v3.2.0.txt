The AISKG v3.2.0 source code, frozen v3.0.0 core, v3.1.2 reviewer-level replay, corrected in-domain benchmark, public-safe external BioRED/BioREDirect metrics and predictions, configuration files, checksums, reference outputs and repository-native Google Colab notebook are available at https://github.com/romenmeitei/AISKG/releases/tag/v3.2.0. Official BioRED/BioREDirect data, source code and model weights are not redistributed; the notebook retrieves them from NCBI and records their resolved commit and SHA-256 hashes. The external analysis uses gold entities and evaluates relation classification. The BC8 test set has been examined and is locked against subsequent tuning.
