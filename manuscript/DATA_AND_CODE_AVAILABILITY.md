# Suggested Data and Code Availability statement

The complete computational workflow and supporting materials are publicly available in the AISKG Framework repository: https://github.com/romenmeitei/AISKG_Framework. Version 3.0.0 unifies literature retrieval, preprocessing, semantic modelling, ontology-guided extraction, knowledge-graph construction, temporal and pathway analysis, expert validation, biomedical NLP benchmarking, research-representation analysis, robustness analysis, and component ablation. The repository provides a central YAML configuration, Google Colab notebook, command-line and Python APIs, frozen checksum-verified inputs, per-stage outputs, reference results, pytest tests, GitHub Actions, SHA-256 manifests, and a deterministic release archive. The frozen manuscript profile reproduces the reported results; optional live bibliographic retrieval may yield different records because databases, indexing, APIs, and software dependencies change over time. Third-party bibliographic fields remain subject to the applicable provider and institutional terms.
