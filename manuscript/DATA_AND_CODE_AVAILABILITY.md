# Data and code availability

The complete AISKG computational workflow, frozen inputs, corrected additional analyses, public metadata-sanitized completed reviewer workbooks, item-level benchmark predictions, expected results, tests, and reproducibility documentation are available at `https://github.com/romenmeitei/AISKG` under release tag `v3.1.2`. The repository preserves the v3.0.0 frozen manuscript-snapshot pipeline and provides deterministic reviewer-level replay of expanded blinded pathway validation together with the corrected AISKG–PubTator 3.0–structured-LLM held-out benchmark. The principal reviewer-facing workflow is `notebooks/AISKG_Framework_v3_1_2_Complete_Reproducibility.ipynb`; equivalent command-line execution is provided by `aiskg additional-analyses`. SHA-256 manifests, source-to-public workbook hashes, 805 paired reviewer ratings, all 92 required adjudications, reconstructed final labels, independent verification scripts, pytest tests, and GitHub Actions are included. Untouched reviewer uploads are excluded from the public repository because their document properties contained a personal account address; public copies are cell-for-cell content-equivalent and metadata-sanitized. The archived structured-LLM predictions and statistics are reproducible, although the source run recorded model revision `main`, so future live model inference is not claimed to be bit-for-bit identical. Live bibliographic retrieval or external API/model calls may change over time. Third-party bibliographic fields remain subject to applicable provider and institutional terms.
