# AISKG Framework v3.0.0

## Major changes

- Merges AISKG Section 1 and Section 2 into one installable Python project.
- Preserves the frozen manuscript outputs through version-pinned compatibility engines.
- Adds one central YAML configuration and CLI/API/Colab entry points.
- Adds nine deterministic ablation configurations.
- Adds publication CSV, XLSX, JSON, GraphML, PNG, Markdown, PDF, and ZIP outputs.
- Adds 285 expected-result and bridge checks.
- Adds pytest tests, GitHub Actions, manifests, SHA-256 checksums, and deterministic packaging.
- Adds the backward-compatible `release_archive` API alias.
